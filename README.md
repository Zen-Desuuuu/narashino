# ならしの日和

習志野市の自然、街の味、季節の楽しみを紹介する、レスポンシブな日本語の観光案内サイトです。外部ライブラリやビルド手順は不要です。

谷津干潟、谷津バラ園、イオンモール津田沼の写真には、撮影者・ライセンスへのリンクを掲載しています。習志野ソーセージの画像は、実物写真ではなくオリジナルのイメージイラストです。

## ローカルで表示する

`index.html` をブラウザーで開いてください。ローカル HTTP サーバーを使う場合は、リポジトリのルートで次を実行します。

```sh
python3 -m http.server 8000
```

その後、ブラウザーで `http://localhost:8000` を開きます。Google Fonts の読み込みにはインターネット接続が必要です。
